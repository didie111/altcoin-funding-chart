## 프로젝트 개요

### 🎯 목적
이 프로젝트는 **암호화폐 선물 거래의 펀딩비(Funding Rate)를 실시간 및 과거 데이터로 시각화**하고, **음펀딩 + RSI 조건 기반 롱 전략을 백테스팅**하는 웹 애플리케이션입니다.

### 💡 핵심 가치
- **6개 거래소 통합**: Binance, Bitget, Bybit, OKX, BingX, MEXC
- **실시간 + 과거 데이터**: 상장 시점부터 현재까지 전체 히스토리 조회 가능
- **정교한 백테스팅**: 1분봉부터 월봉까지 모든 타임프레임 지원
- **데이터 경량화**: IndexedDB 기반 최적화된 캐싱 시스템

### 🏆 특장점
1. **초고속 리샘플링**: 1분봉 마스터 데이터에서 상위 10개 주기 즉시 합성
2. **즐겨찾기 일괄 백테스트**: 여러 코인을 한 번에 전략 테스트
3. **공식 과거 파일 활용**: Binance 공식 히스토리 파일로 API 요청 최소화
4. **펀딩 이력 검색**: 과거 음펀딩 조건 검색 및 차트 이동

## 주요 기능

### 📊 1. 차트 시스템

#### 1.1 멀티 차트 지원
- **1화면 모드**: 단일 전체화면 차트
- **4분할 모드**: 동시에 4개의 독립 차트 운영
- **작업 영역 전체화면**: 브라우저 전체화면 지원

#### 1.2 차트 기능
- 가격 차트 (상단 70%) + 펀딩비 차트 (하단 30%)
- 1분봉 ~ 월봉 (11개 타임프레임)
- RSI 지표 (기간, 소스, 기준선 커스터마이징)
- 실시간 업데이트 (가격 3초, 펀딩비 10초)

#### 1.3 그리기 도구
- 수평선, 수직선, 크로스라인
- 추세선, 레이 (Ray)
- 가격 노트 (Price Note)
- 로컬 저장 및 날짜 이동 기능

### 💰 2. 펀딩비 분석

#### 2.1 실시간 펀딩비
- 현재 미정산 펀딩비율
- 다음 정산 시각 카운트다운
- 정산 주기 자동 감지 (1h, 2h, 4h, 8h, 12h, 24h)

#### 2.2 펀딩 이력 검색
- 특정 펀딩비율 조건으로 과거 검색
- 전체 코인 일괄 검색 지원
- IndexedDB 증분 저장 (중단 후 이어서 가능)
- 검색 결과에서 차트 날짜 이동

#### 2.3 펀딩비 신호
- EXTREME: 매우 극단적인 음펀딩
- WARN: 경고 수준 음펀딩
- 신호 목록에서 원클릭 차트 이동

### 🧪 3. 백테스팅 엔진

#### 3.1 전략 설정
- **진입 조건**: 음펀딩비 + RSI 과매도
- **분할 매수**: 0~10회 (균등 or 마틴게일)
- **추가 진입 신호**:
  - 하락률 기준 (Step %)
  - 현재 주기 RSI 돌파
  - **1분봉 고정 RSI** (첫 진입은 테스트 주기, 추가는 1분봉)
- **청산 조건**: TP(익절), SL(손절), RSI 과매수, 보유 기간 제한

#### 3.2 실행 모드
- **단일 실행**: 하나의 설정으로 백테스트
- **주기 비교**: 1분봉~월봉 전체 주기 동시 비교
- **조건 탐색**: 324개 조합 자동 최적화
- **즐겨찾기 일괄 실행**: 등록된 모든 코인 순차 백테스트

#### 3.3 결과 분석
- 거래 목록 (진입/청산/손익 상세)
- 승률, Profit Factor, MDD
- 자산 곡선 그래프
- 거래별 차트 이동 (선택 가능한 타임프레임)
- CSV 내보내기

### 🔍 4. 스캐너 & 랭킹

#### 4.1 5일 급등락 스캐너
- 최근 5일 가격 변동률 기준
- 급등/급락 필터링
- 실시간 가격 업데이트

#### 4.2 펀딩비 순위
- 음펀딩 순위 (상위 N개)
- 양펀딩 순위
- 거래소별 필터링

### ⭐ 5. 즐겨찾기 시스템

#### 5.1 관리 기능
- 여러 코인 일괄 추가 (줄바꿈/쉼표로 구분)
- 드래그로 순서 변경
- 거래소별/전체 검색
- 직전 변경 되돌리기

#### 5.2 일괄 백테스트
- 모든 즐겨찾기 코인 순차 실행
- 설정 기간 or 전체 과거~현재
- 비교 테이블 (승률/PF/순손익 정렬)
- 중단 후 이어서 실행 가능

- **Node.js**: CLI 백테스팅 도구

## 우리가 작업한 주요 개선사항

### 🚀 2026-10-25 ~ 2026-11-06 작업 내역

#### 0. 백테스팅 캐시 공유 버그 수정 (2026-11-06)
**문제**: 타임프레임/실행모드/세션 간 캐시 재사용 실패
- 1분봉 백테스트 완료 → 3분봉 전환 시 20초+ 재다운로드
- 배치 백테스트 → 개별 차트에서 20초+ 재다운로드
- 새로고침 후 동일 데이터 20초+ 재다운로드

**해결**:
- 커서 기반 캐시 키 → 내용 기반 캐시 키로 변경
  - OLD: `["page-v2", "candles", ex, symbol, tf, end]`
  - NEW: `["candles-v3", ex, symbol, nativeTf, firstTime, lastTime]`
- Native 타임프레임 기반 키 생성
- 레거시 키 자동 마이그레이션
- **캐시 적중률 0% → 90%+ 개선**
- **응답 시간 20초+ → 1초 이내로 단축**

**검증**:
- Property-based testing으로 버그 조건 탐색
- 보존 속성 테스트로 회귀 방지
- `tests/cache-sharing-bug-exploration.test.cjs` 작성 및 통과

#### 1. 캐시 시스템 최적화 (2026-11-06)
**문제**: IndexedDB 캐시가 3GB 이상 비대화
**해결**:
- `binance-official-zip-v1` 키 854개 (945MB) 삭제
  - Binance 공식 ZIP 파일 캐싱 버그 수정
  - 불필요한 중복 저장 제거
- 캐시 정리 후 **3GB → 300MB로 90% 경량화**
- LRU 알고리즘으로 32MiB 상한 유지
- 오래된 페이지 자동 삭제 (과거 30일, 최신 60초)

#### 2. 1분봉 마스터 리샘플링 (2026-11-04)
**기능**: 초고속 전체 주기 백테스트
**구현**:
- 1분봉 1회 수집 → 상위 10개 주기 인메모리 합성

- 수십 분 소요 → 수초로 단축

## 백테스팅 시스템 상세

### 📐 계산 가정

#### 진입/청산 시점
- **기본**: 완성 봉 확인 → 다음 봉 시가 체결
- **1분봉 고정 RSI**: 1분봉 단위 추가 진입 (첫 진입은 테스트 주기 RSI)
- **TP/SL**: 보유 중 봉의 고가/저가 감시

#### 체결 우선순위
1. 시가 갭으로 TP/SL 도달 → 시가 체결
2. 봉 내 TP와 SL 동시 도달 → SL 우선
3. 추가 진입 전 고가 → 새 평단 TP 재사용 금지

#### 수수료 및 슬리피지
- 기본 수수료: 0.05% (Taker)
- 슬리피지: 0.01%
- 펀딩비: 보유 중 실제 정산 반영 (양수 지급 + 음수 수취)

#### 정산 기록 사용
- **confirmed 모드** (기본): RSI 마감 시각까지 확정된 정산만 사용
- **chart 모드**: 차트 관측 간격 (사후 비교, 미래 정보 포함 경고)

### 🔄 백테스트 워크플로우

#### 1. 데이터 수집
```
종목 선택 → 기간 설정 → 타임프레임 선택
    ↓
가격 캔들 페이지 조회 (market-api.js)
    ↓
펀딩 정산 이력 조회 (funding-history.js)
    ↓
1분봉 보조 데이터 (옵션, 1분봉 고정 RSI 사용 시)
    ↓
64비트 OHLCV 블록 변환 (backtest-bars.js)
```

#### 2. 전략 계산
```
Worker 스레드 실행 (backtest-worker.js)
    ↓
RSI 계산 (indicators.js)
    ↓
진입 조건 검사 (funding + RSI)
    ↓
분할 매수 실행
    ↓
TP/SL/RSI 청산 감시
    ↓
펀딩비 정산 반영
    ↓
거래 목록 + 자산 곡선 생성
```

#### 3. 결과 표시
```
거래 테이블 렌더링
    ↓
성과 지표 계산 (승률, PF, MDD)
    ↓
차트 오버레이 (backtest-overlay.js)
    ↓
CSV 내보내기 (옵션)
```

## 알려진 이슈 및 주의사항

### ⚠️ 주의사항

#### 1. 메모리 제한
- **캔들 예산**: 256~768 MiB (보고 메모리 기준) or 최대 1,600만 봉
- 장기 백테스트 (10년+ 1분봉) 시 메모리 부족 가능
- 해결: 기간 분할 실행 or 상위 타임프레임 사용

#### 2. API Rate Limit
- 거래소마다 요청 제한 존재
- 자동 재시도 (최대 3회)
- 60초 이상 대기는 사용자 확인 필요
- 일괄 백테스트: 순차 실행으로 간격 준수

#### 3. 데이터 범위
- 거래소가 제공하는 범위만 조회 가능
- 상장 이전 데이터는 합성하지 않음
- 펀딩 이력과 캔들 범위는 다를 수 있음

#### 4. 백테스트 정확도
- **실제 체결과 다를 수 있음**: 슬리피지, 호가창, 유동성 미반영
- **1배 롱만 가정**: 레버리지, 강제청산 미반영
- **검증용 도구**: 실제 거래 전 별도 검증 필수

#### 5. 브라우저 호환성
- **권장**: Firefox, Chrome 최신 버전
- **필수**: IndexedDB, Web Workers 지원
- **모바일**: 일부 기능 제약 (4분할 등)

## 문제 해결 가이드

### 🔧 자주 묻는 질문 (FAQ)

#### Q1. 차트가 로드되지 않아요
**A**: 다음을 확인하세요:
1. 서버가 실행 중인지 확인 (`http://localhost:3000`)
2. 브라우저 콘솔에서 오류 메시지 확인 (F12)
3. IndexedDB가 활성화되어 있는지 확인
4. 사이트 데이터 삭제 후 재시도

#### Q2. 백테스트가 매우 느려요
**A**: 다음을 시도하세요:
1. 기간 단축 (1년 → 6개월)
2. 상위 타임프레임 사용 (1분봉 → 5분봉)
3. 1분봉 고정 RSI 끄기
4. 조건 탐색 대신 단일 실행

#### Q3. 캐시가 너무 커요 (3GB+)
**A**: 
1. 브라우저 사이트 데이터 삭제
2. 일괄 백테스트 중단 후 캐시 정리
3. 과거 페이지는 30일 후 자동 삭제됨

#### Q4. BingX/MEXC가 안 돼요
**A**:
1. 중계 서버 상태 확인: https://altcoin-market-relay.artfulscout128.chatgpt.site
2. `relay-config.js`에서 중계 URL 확인
3. CORS 오류 시 서버 재시작

#### Q5. 일괄 백테스트가 중단됐어요
**A**:
- 자동으로 진행 저장됨
- "이어서 실행" 버튼 클릭
- 완료된 코인은 재계산 스킵

#### Q6. 거래 결과가 이상해요
**A**: 다음을 확인하세요:
1. 데이터 범위 경고 메시지
2. 펀딩 이력 누락 여부
3. "진입 조건 검토" 탭에서 제외 사유 확인
4. CSV 내보내기로 상세 분석

#### Q7. 즐겨찾기 일괄 추가가 안 돼요
**A**:
1. 심볼을 줄바꿈 or 쉼표로 구분
2. 거래소가 지원하는 USDT 무기한 계약인지 확인
3. `1000SATS`처럼 수량 접두어는 그대로 입력
4. 확인 다이얼로그에서 미확인 심볼 제외
