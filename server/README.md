# BingX / MEXC 시장 데이터 중계

GitHub Pages에서 BingX와 MEXC를 직접 요청하면 브라우저의 출처 정책 또는 거래소 접근 제한 때문에 공식 응답을 읽지 못할 수 있다. `relay-config.js`에 지정된 서버가 두 거래소의 공개 시장 데이터만 조회한다. 나머지 거래소는 기존 경로를 사용한다.

- 현재값: BingX premiumIndex, MEXC funding_rate
- 정산 이력: BingX fundingRate, MEXC funding_rate/history
- 캔들: BingX swap v3 klines, MEXC contract kline
- 전체 종목 목록: BingX contracts, MEXC contract/detail
- 전체 24시간 시세: BingX ticker, MEXC contract/ticker
- 정산 주기: 현재값 응답의 fundingIntervalHours / collectCycle

`market-relay.mjs`는 Sites 서버의 동일 파일을 보관한 사본이다. 서버 소스를 수정할 때는 두 저장소의 파일을 함께 갱신한다. 서버는 `GET /api/market`의 exchange/path와 허용된 매개변수만 받아 공식 URL을 구성한다. 브라우저의 Origin, 쿠키, 인증 정보는 거래소로 전달하지 않는다. 임의 URL, 개인 계정, 주문 API는 지원하지 않는다.

성공한 현재값은 최대 3초, 캔들과 이력은 최대 10초 보관한다. 요청 간에는 완료된 JSON 문자열과 예약 시각만 보관하며, 실행 중인 fetch나 Promise는 공유하지 않는다. 취소된 요청이 다음 요청을 막지 않도록 각 호출의 취소 신호와 응답 제한을 독립적으로 적용한다. 실패한 응답은 이전 성공값으로 대체하지 않는다. `X-Market-Fetched-At`을 차트에 전달해 실제 조회 시각을 표시한다. BingX 요청은 숫자 시각으로 순서를 예약해 간격을 두고 timestamp를 생성하며, 네트워크 실패일 때만 공식 보조 주소를 이용한다.

BingX 정산 이력은 endTime만 전달할 때 성공 코드와 null 데이터가 반환되는 것을 확인했다. 90일의 startTime/endTime 구간을 함께 전달해 정산 기록을 조회하고, 가장 오래된 기록의 직전 시각으로 구간을 옮겨 과거 이력을 계속 수집한다. 성공 코드의 null 이력은 빈 정산 기록으로 처리한다.

차트 타임프레임은 1m / 3m / 5m / 15m / 30m / 1h / 2h / 4h / 1d / 1w / 1M이다. 주봉은 월요일 00:00 UTC, 월봉은 달력의 월 경계를 사용한다. 6개 거래소의 원본 주봉·월봉을 조회하고, 월봉을 30일봉으로 합성하지 않는다. MEXC의 3m는 Min1, 2h는 Min60의 실제 OHLCV를 UTC 경계에 맞춰 합성한다. Bitget의 과거 2h도 1H를 합성한다. 원본 봉이 누락된 과거 합성 봉은 만들지 않으며, 페이지 경계의 불완전한 봉은 다음 페이지에서 다시 조회한다.

로컬 개발은 localhost, 127.0.0.1, [::1]의 HTTP/HTTPS 출처를 허용하며 허용된 출처만 정확하게 CORS 응답에 반영한다. 임의 외부 출처와 localhost를 흉내 낸 도메인은 허용하지 않는다.

Bitget 최신 캔들 요청에는 endTime을 넣지 않아 진행 중인 봉을 포함한다. 과거 페이지는 API가 endTime을 봉 경계로 내림하는 규칙을 고려해 커서를 올림한 뒤 요청하므로 페이지 사이의 한 봉이 빠지지 않는다.

하단 날짜 이동 버튼 또는 Alt+G로 한국 시간(UTC+9)을 지정한다. 아직 수집하지 않은 구간은 날짜 주변 캔들을 직접 조회하며, 수집 완료 시 현재 화면의 날짜를 유지한다. 전체 캔들 수집에 3,000봉 같은 고정 상한은 없지만 상장 시점과 거래소 API의 실제 보관 범위를 넘을 수는 없다. 가격 캔들과 정산 기록의 제공 범위는 다를 수 있다. 기록 없는 날짜를 최신 날짜나 가짜 값으로 대체하지 않는다.

차트 좌우 이동 시 화면 가장자리와 아직 불러오지 않은 구간의 캔들을 요청한다. 전체 이력 수집 중에도 먼저 수집된 페이지를 사용할 수 있다. 과거 전체 수집을 중지해도 실시간 갱신과 이동 구간 조회는 계속된다. 날짜 이동은 선택한 봉을 중앙에 맞추며, 이력 추가 중에는 시각을 기준으로 화면을 유지한다.

실시간 캔들은 3초, 현재 펀딩비는 10초, 정산 이력은 60초마다 요청한다. 최신 봉은 `update`로 거래량·펀딩비 시간점·RSI·정산 주기와 함께 갱신하며, 뒤늦은 과거 페이지가 현재 봉을 덮어쓰지 않는다. RSI는 재귀 계산 상태를 이어 사용하며, 아직 수집하지 않은 시간 간격은 이어서 계산하지 않는다. 현재 미정산 구간의 주기는 공식 응답 또는 최근 정산 간격을 사용하며, 과거 기록이 없는 구간에는 현재 정책을 소급하지 않는다.

가격축의 현재가 아래에는 각 타임프레임 봉의 남은 시간이 표시되고 시간축 오른쪽에는 한국시간 시계가 표시된다. 이동 버튼은 차트 위에 마우스가 있거나 키보드로 버튼에 접근한 경우 표시된다. RSI 설정의 모습 탭에서 상단·중간·하단 기준선의 표시, 값, 색상, 두께, 선 모양을 각각 변경할 수 있다.

4분할 차트는 `chart-workspace.js`가 기존 차트와 3개의 독립 차트 문서를 구성한다. 1화면으로 돌아가면 추가 문서를 제거하고 시세 요청을 취소한다. 분할에서는 최근 캔들을 우선 조회하고 과거 구간은 이동 시 추가 조회한다. `market-shared.js`가 차트 간 같은 요청, 짧은 캐시, BingX 요청 간격을 공유한다. 한 차트의 취소는 다른 차트의 조회를 중단하지 않는다. 분할 캔들은 약 9초, 현재 펀딩비는 약 20초 간격으로 갱신해 BingX의 공유 요청 간격을 지킨다. 단일 화면의 캔들 3초·현재값 10초 갱신은 유지한다.

종목 이름을 누르면 `symbol-picker.js`가 6개 거래소의 거래 가능한 USDT 무기한 계약을 검색·즐겨찾기·현재가·24시간 등락·거래대금과 함께 표시한다. `market-catalog.js`는 Bybit의 모든 cursor 페이지를 조회한다. 목록에서는 화면에 보이는 행만 만들고, 열린 동안에만 시세를 갱신한다. 종목 정보는 최대 5분 캐시하며 갱신 실패 시 이전 목록임을 표시한다.

각 분할의 상단 최대화 버튼이나 오른쪽 아래 확대 버튼은 해당 차트만 펼치며, 다시 누르거나 Alt+Enter / Esc로 4분할에 복귀한다. 선택한 차트에서 Alt+Enter도 같은 동작을 한다. 확대 중에도 나머지 차트 문서와 설정을 유지하고, 복귀할 때 새 조회나 문서 재생성을 하지 않는다. 상단의 별도 `작업 영역 전체화면` 버튼으로 브라우저 전체화면을 전환할 수 있으며, 그 안에서도 각 차트 최대화가 동작한다.


## 공식 상장폐지 공지

`server/delisting-news.mjs`는 동일 Sites 프로젝트의 `GET /api/news`에서 사용하는 읽기 전용 수집기다. Binance·Bybit·OKX의 공식 공지 API, Bitget·BingX·MEXC의 공식 공지 페이지에서 제목·게시일·원문 주소를 읽는다. MEXC는 공식 공지의 mexc.fm 도메인에서 같은 목록을 읽고 원문은 mexc.com으로 연결한다. 임의 URL·개인 정보·주문 요청은 받지 않는다. 이 파일도 Sites 소스와 함께 갱신한다.

성공한 거래소별 목록은 15분, 실패 상태는 2분 보관한다. 완료된 값만 요청 사이에 보관하며 진행 중인 Promise는 공유하지 않는다. 실패 시 그 출처의 이전 공지를 유지하고 `sources[exchange].status=error`로 구분한다. 지역에 따라 제공하는 공식 공지가 다를 수 있다. 브라우저는 `data/delistings.json`의 2026-10-24 공식 공지 수집본과 중계 응답을 합쳐 중복을 제거하고, 오류를 최신 조회 성공으로 표시하지 않는다. 출처별 확인 상태와 공식 공지 목록 링크를 제공한다. 뉴스는 가격 데이터 요청과 독립적이며, 4분할의 하위 문서에서는 수집하지 않는다.

게시일은 종료일이 아니다. `effectiveAt`은 원문에서 확인한 일정에만 넣는다. 시간대가 명시되지 않은 페이지 날짜는 날짜만 표시하며, 연기·취소 공지는 일정 변경으로 분류한다. 현물·Alpha·USDC/주식 선물 공지를 임의의 USDT 무기한 차트로 연결하지 않는다.

## 백테스팅 패널

`dashboard.js`와 `dashboard.css`는 작업 영역의 공유 하단 패널과 뉴스 UI를 제공한다. `dashboard-model.js`는 공식 링크 검증·검색·중복 처리·설정 검증을 맡는다. 기간(KST 날짜)·초기 자본·주문 비율·수수료·슬리피지 설정은 브라우저에 저장한다. 하단 패널은 열기/접기, 높이 조절, 최대화/복원, 리포트 탭을 지원하며 활성 분할의 종목·주기를 따른다. 전체화면 안에서도 사용할 수 있다. 이번 버전에는 백테스팅 계산·체결·수익률 생성이 없으며, 실행은 비활성화한다.
