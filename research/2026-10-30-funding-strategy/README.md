## 실제 데이터 수집과 저장

정산 조건은 실제 과거 기록으로 전 기간을 먼저 검사한다. 가격은 조건이 유효했던 구간 앞 200봉 및 최대 보유 종료 뒤까지 실제 캔들을 조회한다. 데이터 로더의 RSI 준비 봉도 추가된다. 겹치는 구간을 합치며, 신호가 나올 수 없는 긴 비활성 구간 전체의 가격을 불필요하게 보관하지 않는다. 실제 공백은 엔진이 감지하고, 공백 청산이 생긴 조합은 좋은 전략 후보에서 제외한다. 오래된 캔들이 없으면 더미로 채우지 않고 누락 범위를 남긴다. 원래 계약이 없는 경우 비슷한 심볼을 임의 대입하지 않는다.

API 페이지와 정규화 원본의 해시, 실제 첫·마지막 시각, 완료 여부, 실패 원인은 `collection.json` 및 압축 캐시에 보관한다. `.cache/`는 대용량 시장 자료로 Git에 올리지 않는다. 중단 시 완료된 정산 페이지와 가격 구간부터 재사용한다.
